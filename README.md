# MANDOUBEMBETA

Protótipo de uma plataforma de delivery com identidade visual própria.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
- Layout responsivo

## Funcionalidades

- Busca de restaurantes
- Filtro por categoria
- Cards de restaurantes
- Carrinho lateral
- Adição e remoção de itens
- Cálculo do total
- Layout responsivo para celular e desktop
- Identidade visual preto + laranja

## Como executar

Não é necessário instalar dependências.

Abra `index.html` diretamente no navegador ou use uma extensão como Live Server no VS Code.

## Publicar no GitHub

Dentro desta pasta:

```bash
git init
git add .
git commit -m "primeiro commit"
git branch -M main
git remote add origin https://github.com/kauacgoncalvess-sudo/MANDOUBEMBETA.git
git push -u origin main
```

## Observação

Este é um protótipo front-end. Login real, banco de dados, pagamentos, geolocalização, pedidos em tempo real e painel administrativo ainda precisam de um backend e integrações.
